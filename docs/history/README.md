## 维护规则（2026-11-14 修订）

- 普通状态变化由 Git 保存，不再为现值重写、旧行或体量搬移机械创建归档。
- 只有独立具备长期检索价值的事件报告或前向任务书才新建文件，并加入索引。
- 重要事件报告保留原文，不做摘要重写；一次性操作指引须标“留档，勿再执行”。
- 前向任务书须标生命周期：执行前通读；全部执行完后标“已执行，勿再执行”。
- 单文件达到 500 行时自查可读性；确需精炼时保留事件结构、判据与证据，原文可由 Git 恢复。
- 既有机械搬迁档案若含唯一历史上下文，继续保留；不因名称含“归档”就删除。
