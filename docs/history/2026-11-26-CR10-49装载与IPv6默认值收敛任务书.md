## 4. 步骤 C：IPv6 默认值隐患

### 4.1 实测证据（2026-11-26，本机）

| 读数 | 结果 |
|---|---|
| `node -e` 的 `dns.lookup('localhost',{all:true})` | `[{"address":"::1","family":6},{"address":"127.0.0.1","family":4}]`，IPv6 优先 |
| 宿主 3000 端口监听 | 仅 `127.0.0.1:3000`，无 `::1` 监听 |
| Python `urllib` → `http://127.0.0.1:3000/api/health` | 200，15–37 ms |
| Python `urllib` → `http://localhost:3000/api/health` | 200，**2029–2048 ms** |
| Python `urllib` → `http://[::1]:3000/api/health` | `URLError`（Connection refused），约 2040 ms |
| 对照：IPv4 关闭端口 9999 | `ConnectionRefusedError`，**2013–2035 ms** |
| 容器内 `host.docker.internal` 解析 | 同时得到 `192.168.65.254` 与 `fdc4:f303:9324::254` |
| 容器内直连 `fdc4:f303:9324::254:3000` | `OSError [Errno 101] Network is unreachable` |

### 4.2 归因

- 约 2 秒不是 IPv6 独有代价：IPv4 的关闭端口同样约 2 秒才拒绝，属本机对丢弃 SYN 的重传等待。
- IPv6 的真实代价是**每次都先撞一次空端口再回落**：`localhost` 优先解析 `::1`，服务只监听 `127.0.0.1`，顺序尝试的客户端每次白付一次约 2 秒。
- Node 侧未受害：Node 26 的 `fetch` 走 Happy Eyeballs，实测 `http://localhost:3000/api/health` 200 仅 15–23 ms。
- Python 侧受害：`urllib`／`requests` 顺序尝试，实测每次约 2.0 秒。

### 4.3 影响面

`localhost` 作为默认值出现在 DS 回调 web 的位置：

```text

data-service/app/us_list_job.py:704      WEB_BASE_URL 默认 http://localhost:3000
data-service/app/hotspot/pipeline.py:52  WEB_BASE_URL 默认 http://localhost:3000

data-service/app/mcp_server.py:34-38     WEB_API_BASE 回退 http://localhost:3000

web/app/api/quote/route.ts:7             DATA_SERVICE_URL 默认 http://localhost:8000
```

正式容器不受影响：`docker-compose.yml` 显式给 `WEB_BASE_URL`／`WEB_API_BASE` 为 `http://web:3000`、`DATA_SERVICE_URL` 为 `http://data-service:8000`，均走 compose DNS 的 IPv4 名。受害面是**开发态默认值**与任何未显式配置的部署。

3. 当前实现：`E:\Python\pythoncore-3.15-64\python.exe` + `subprocess` 调 `docker cp`/`docker exec`。**顺带修掉一个真 bug**：`DEADLINE` 是 naive、`now()` 是 aware，`now() >= DEADLINE` 抛 `TypeError`，进程当场死（pid 30420）。`--once` 不走到那行所以没暴露；`Start-Process` 不带重定向时 traceback 被吞掉，表现为"又静默死了"。⇒ 已补 `CRASH` 分支：任何未捕获异常都落一行到日志，不再让「死掉」长得像「还在跑」。

**旧日志的 14 行中文是损坏的**（23:56–01:01 那一段）。那是当时环境的真实产物，**不篡改**；新增行均为干净 UTF-8，文件 BOM 已剥离（`Add-Content -Encoding utf8` 在 PS5.1 会写 BOM，首行 JSON 将无法解析）。
