## 一、#95 定档：留首次出现

- 决定：同一 (type, code) 出现两条以上时，**保序留首次出现**那一条；不合并字段、不留末次、不碰唯一键。
- 依据：上游列表顺序有含义（crypto 按市值降序、stock/fund/hk 按主源序）；CR10-15 已把“首次优先”落成 crypto 的名单／单发／批量三处同解；留末次会让名单与单发报价各说各话。库内现查 (type, code) 重复组＝0，不需要迁库或删行。
- 落码（CR10-21，commit 873619d）：
  - web/lib/sync.ts 新增 keepFirstByTypeCode()；在 findDuplicateCodes() 之后、判空与缩水闸之前执行去重；
  - dupCodes 仍挂在成功／缩水／失败三条返回上，继续点名被丢的键（上限 20 枚；去重作用于全部重复）；
  - 成功返回的 count 用去重后的 rows.length；同 code 不同 type 不算重复；
  - 不碰 data-service 的 crypto provider 去重，也不碰 Prisma schema。
- 测试：web/lib/sync-dup-codes.test.ts 由 8 枚增至 13 枚（新增留首条、同 code 不同 type、空表、25 组重复仍截 20、接线次序）；全量 vitest 608/608·63 文件。
