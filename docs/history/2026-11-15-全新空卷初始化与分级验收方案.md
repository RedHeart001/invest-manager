## 一、目标与不变边界

### 1. 目标形态

- 个人本机仅回环使用，Docker Compose 为唯一日常运行形态。
- 正式 Compose 项目为 `invest-manager`，正式镜像使用 `invest-manager-web:local` 与 `invest-manager-data-service:local`。
- Web 只绑定 `127.0.0.1`，data-service 不发布宿主机端口，MCP profile 默认不启动。
- SQLite 使用全新正式命名卷，备份落正式 `./backups`；不挂接开发库、隔离库或隔离 backups。
- 开发与 Docker 不得同时写同一数据库；最终只保留一套日常调度。

### 2. 不变护栏

1. 不读取、输出或提交 `.env`、密钥和业务数据；凭据只在本地安全注入。
2. 正式空卷建立和离线基线不触发真实行情、热点、LLM、全量同步或付费请求。
3. 真实主数据初始化、行情/契约、热点/LLM、完整七套和自然调度分别按窗口授权。
4. 历史全绿、fixture、合成回调和合成浏览器证据不得冒充真实外部或自然调度证据。
5. 外部源失败、代码回归和运维问题分账；不为凑全绿反复购买请求或放宽断言。
6. 每阶段记录起跑时间、HEAD/工作树、实际命令、exit code、回执路径和开发态前后指纹。
7. 不操作无关 `workbuddy2api`，不擅自重启 Docker Desktop；提交、push、现场清理分别确认。
