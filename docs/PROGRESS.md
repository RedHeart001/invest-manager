### ✅ 搜索页无结果且无样式（dev/build 冲突）

原因：在 `next dev` 运行期间执行 `npm run build`，build 覆写 `.next` 致路由表与静态资源错乱。约定：开发期间**不在 dev server 运行时执行 `npm run build`**；类型检查改用 `npx tsc --noEmit`。

### ✅ 加密货币数据源（09-27 结案：可达，此前"不可达"是配置缺失不是外网不通）

原文"当前网络不可达"已被 **CR9-41** 推翻：根因是 `main.py:12` 的 `NO_PROXY=*` 连带屏蔽了 Windows 注册表系统代理，而 CoinGecko 只能走该代理；起 ds 时显式给 `HTTPS_PROXY` 即 `/products?type=crypto` 250 只、`/product/crypto/BTC` 200。类型完整率 4/6→5/6（只剩 hk）。已由 R12 策略覆盖 + 待拍板第 14 条走 A 固化进模板与 PLAN（09-27 15:2x）。
