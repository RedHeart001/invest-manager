# 热点日报生成

## 适用场景
用户想要一份"今天市场发生了什么"的汇总，或询问当前热点及关联产品。

## 执行步骤

1. **取热点**：调用 `get_hotspots` 获取当日 digest（标题、板块标签、引擎与降级状态）。
2. **判断数据完整性**：
   - 若返回为空或 `degraded=true`，**先如实说明数据缺口**（例如"当前热点源不可用/尚未抓取"），不要编造热点。
   - 若 `engine=keyword`，说明这是关键词回退结果，结构化程度有限。
3. **关联产品**：对每条热点的板块标签，用 `search_products` 查找相关基金/股票（板块标签可直接作为关键词）。
   - 只推荐**搜索结果中真实存在**的产品，附上代码与最新价。
   - 板块名命中的基金优先给出；股票需要明确的板块归属，不要凭印象列举。
4. **行情校验**：对重点标的（不超过 3 个）用 `get_quote` 取实时价，交叉印证热点是否在盘面上有反应。
5. **输出日报**（Markdown）：
   - 首行给出日期与数据时点说明。
   - 每条热点一段：标题 → 板块/概念 → 相关产品（含代码、最新价、涨跌幅）→ 一句话解读。
   - 涉及原因时一律使用"**可能相关**"，不做因果断言。

## 硬性约束
- 不编造热点、板块与产品；数据缺失就显式写"数据缺口"。
- 不给出买卖建议；结尾附"仅供参考，不构成投资建议"。
- 若用户追问某个标的的深度分析，提示可用"深度分析 <代码>"触发（L2 研报，约 2~5 分钟）。
