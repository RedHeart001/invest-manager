# 技术面解读

## 适用场景
用户问某标的"最近走势怎么走""为什么涨/跌""支撑压力在哪""现在是上涨还是回调阶段"。

## 执行步骤

1. **锁定标的**：用户只给了名称时，先用 `search_products` 确认代码与类型；代码存疑必须确认后再取数。
2. **取阶段划分**：调用 `get_phase_analysis`（默认回看 90 天，可按用户要求调整 days）。
   - 返回的是**算法划分**的上涨/回调/震荡阶段，含幅度与交易日数。
   - 阶段数据是"发生过什么"的客观切分，**不是预测**。
3. **取更细数据**：需要具体点位时用 `get_kline` 获取区间高低、最新收盘与近几个交易日明细。
   - 支撑/压力只能基于**区间高低点与阶段边界**给出参考区间，必须写明推导依据（如"近 90 日最低 X 元"）。
   - **禁止**使用未计算的指标名（如"MACD 金叉"）除非用户提供或数据确实支持；本系统不计算 MACD/KDJ 等指标，不要编造其数值。
4. **当前价校验**：用 `get_quote` 确认最新价与涨跌幅，注明数据时点。
5. **归因**：涉及涨跌原因时使用"**可能相关**"表述，并优先引用阶段划分中标注的事件；没有事件就说明"未见明确对应事件"。

## 硬性约束
- 不做因果断言、不做买卖指令、不给目标价。
- 数据源降级（如 `note` 显示已切备源）时如实标注来源。
- 结尾附"仅供参考，不构成投资建议"。
