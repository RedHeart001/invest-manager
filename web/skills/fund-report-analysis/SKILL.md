# 基金定期报告解读

> 数据源说明：报告清单与行业配置来自 `get_fund_report`（东财披露口径，缓存 6 小时）；
> 前十大重仓来自 `get_fund_holdings`；净值表现来自 `get_kline` / `get_quote`。
> 基金有专属"定期报告"渠道与费率口径，**不要套用股票分析框架**。

## 执行步骤

1. **确认标的**：场外基金代码（6 位）；用户只给名称时先用 `search_products` 确认。
2. **取报告数据**：调用 `get_fund_report(code)`。
   - **报告清单**：给出最近几期定期报告（季报/半年报/年度报告）的标题与披露日期，说明这是披露记录、不含全文。
   - **行业配置**：给出最新披露期（`asOf`）的前几大行业及占净值比例。
   - 若 `degraded=true` 或字段为空，**如实说明该字段数据缺口**，改用手头可得的数据继续分析。
3. **取持仓**：调用 `get_fund_holdings(code)` 拿前十大重仓（含季度口径）。这是**披露滞后**数据，务必标注披露期。
4. **取净值表现**：用 `get_kline`（type=fund）看区间涨跌与最新净值/日增长率；如需实时价用 `get_quote`。
5. **交叉解读**（本技能的价值点）：
   - 把「行业配置」与「重仓行业分布」对照，看是否一致；不一致时提示可能的调仓方向（**表述为"可能"**）。
   - 把「定期报告披露期」与「净值阶段表现」对照，指出报告期后是否出现明显变化。
6. **输出结构**：
   - ① 基金概况（名称/代码/类型）② 定期报告披露情况 ③ 行业配置 ④ 前十大重仓 ⑤ 区间净值表现 ⑥ 综合观察（谨慎表述）。

## 硬性约束
- 定期报告与持仓均为**披露滞后数据**，必须写明截至日期，禁止当作实时持仓。
- 不推断未来业绩、不做买卖建议；涉及原因用"**可能相关**"。
- 数据缺口显式标注（如"本期行业配置未取得"），不得用常识数字填充。
- 结尾附"仅供参考，不构成投资建议"。
